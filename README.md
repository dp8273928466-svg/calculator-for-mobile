# Calca 🧮

A sleek, mobile-responsive dark-mode calculator web application built with vanilla web technologies. Designed for a seamless, native-app experience across mobile and desktop devices.

![Calca Preview](https://img.shields.io/badge/status-live-success)
![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

## ✨ Features

* **Mobile-First Glassmorphism UI:** Clean dark-mode interface optimized for smartphone screens with zero unwanted scrollbars.
* **Haptic Feedback:** Integrates the Web Vibration API (`navigator.vibrate`) to give subtle tactile feedback on every button tap.
* **Interactive History Drawer:** Easily view past calculations, review results, and tap any history item to reuse its result instantly.
* **Keyboard Support:** Full hardware keyboard integration for fast desktop calculations.
* **Responsive Layout:** Locked viewport architecture that prevents overflow and layout shifting.

## 🛠️ Tech Stack

* **HTML5** – Semantic structure
* **CSS3** – Custom styling, CSS Grid, and dynamic viewport units (`100dvh`)
* **JavaScript (ES6)** – Calculator logic, event handling, and vibration triggers
